# Leadflow

Leadflow is a lead capture and follow-up automation system for small businesses that need to respond to enquiries faster.

## Problem

Many businesses lose potential customers because new enquiries sit inside WhatsApp, email, Instagram DMs, or form submissions without a clear follow-up process.

## Solution

Leadflow gives a business one place to collect leads, notify the owner, track the status, and schedule the next follow-up.

## Planned Features

- Public lead form
- Lead database
- Lead status tracking
- Email confirmation for customers
- Telegram alert for the business owner
- Follow-up reminder
- Admin dashboard
- CSV export

## Stack

- Next.js
- FastAPI
- PostgreSQL
- Redis
- Docker Compose
- Telegram Bot API

## Business Value

- Faster response to new leads
- Better follow-up tracking
- Less manual copying between tools
- Clearer sales pipeline for small teams

## Portfolio Notes

This project is designed as a reusable demo for agencies, real estate agents, salons, consultants, schools, and local service businesses.
